# Hardware y software

Cuando utilizas un ordenador para jugar, navegar por Internet, editar un vídeo o hacer un trabajo de clase, están interviniendo dos elementos fundamentales:

- **Hardware:** la parte física del equipo.
- **Software:** los programas e instrucciones que hacen funcionar el equipo.

Ambos se necesitan mutuamente.

<img
  src="/digitalizacion-4eso/img/ud1/hardware-software.png"
  alt="Esquema visual de la relación entre hardware y software"
  className="img-center"
/>

:::tip[Idea clave]

Un ordenador necesita **hardware y software trabajando juntos**.

El hardware aporta los componentes físicos y el software indica qué tareas debe realizar el equipo.

:::

---

## 1️⃣ ¿Qué es el hardware?

El **hardware** es el conjunto de componentes físicos de un sistema informático.

Es decir, todo aquello que podemos **ver y tocar**.

Por ejemplo:

- procesador (CPU),
- memoria RAM,
- placa base,
- unidad SSD,
- tarjeta gráfica,
- monitor,
- teclado,
- ratón,
- webcam.

Podemos encontrar hardware tanto **dentro** como **fuera** del ordenador.

### 🟩 Hardware interno

Son los componentes situados dentro del equipo.

Algunos de los más importantes son:

| Componente | Función principal |
|---|---|
| **CPU** | Ejecuta instrucciones y realiza cálculos. |
| **RAM** | Mantiene temporalmente los datos y programas que estamos utilizando. |
| **SSD** | Almacena permanentemente programas y archivos. |
| **GPU** | Procesa los gráficos y las imágenes. |
| **Placa base** | Permite conectar y comunicar los componentes. |
| **Fuente de alimentación** | Proporciona energía eléctrica al equipo. |

:::info[Recuerda]

No hace falta memorizar todavía todos los componentes.

Durante esta unidad los estudiaremos con más detalle. Por ahora, quédate con una idea: **cada componente realiza una función diferente y todos trabajan juntos**.

:::

### 🟧 Hardware externo

También existen dispositivos físicos conectados al ordenador.

Por ejemplo:

- monitor,
- teclado,
- ratón,
- impresora,
- auriculares,
- webcam,
- memoria USB.

Muchos de estos dispositivos reciben el nombre de **periféricos**.

Más adelante veremos cómo se clasifican.

---

## 2️⃣ ¿Qué es el software?

El **software** es el conjunto de programas, instrucciones y datos que permiten utilizar un sistema informático.

El software **no es un componente físico**.

Por ejemplo:

- Windows,
- Google Chrome,
- LibreOffice,
- Minecraft,
- Spotify,
- Visual Studio Code.

Aunque no podamos tocar un programa, necesitamos hardware para poder ejecutarlo.

### 🟥 Dos grandes tipos de software

Para empezar, podemos distinguir dos grupos principales:

| Tipo | ¿Para qué sirve? | Ejemplos |
|---|---|---|
| **Software de sistema** | Gestiona el ordenador y sus recursos. | Windows, GNU/Linux, macOS |
| **Software de aplicación** | Permite realizar tareas concretas. | Chrome, Word, Canva, juegos |

El **sistema operativo** es especialmente importante porque actúa como intermediario entre el hardware, las aplicaciones y el usuario.

<img
  src="/digitalizacion-4eso/img/ud1/capas-sistema.png"
  alt="Esquema de usuario, aplicaciones, sistema operativo y hardware"
  className="img-center"
/>

Cuando abres un navegador, por ejemplo, el navegador no controla directamente todos los componentes del ordenador. El **sistema operativo gestiona los recursos que necesita**.

:::info[Recuerda]

De forma simplificada podemos pensar en estas cuatro capas:

**Usuario → Aplicaciones → Sistema operativo → Hardware**

:::

---

## 3️⃣ Hardware y software trabajan juntos

Imagina que quieres ver un vídeo en Internet.

¿Qué interviene?

1. El **navegador** solicita y reproduce el vídeo.
2. El **sistema operativo** gestiona los recursos necesarios.
3. La **CPU** procesa instrucciones.
4. La **RAM** mantiene temporalmente los datos necesarios.
5. La **GPU** ayuda a procesar las imágenes.
6. La tarjeta de red o el adaptador Wi-Fi permite recibir los datos.
7. El **monitor** muestra el vídeo.
8. Los **altavoces o auriculares** reproducen el sonido.

Por tanto, una tarea aparentemente sencilla necesita la colaboración de **hardware y software**.

:::tip[Idea clave]

No debemos pensar en el ordenador como una colección de piezas independientes.

**El rendimiento final depende del conjunto: hardware + software + necesidades del usuario.**

Esta idea será muy importante cuando tengamos que elegir un ordenador.

:::

---

## 4️⃣ Un mismo ordenador, diferentes necesidades

No todos necesitamos el mismo tipo de ordenador.

<img
  src="/digitalizacion-4eso/img/ud1/perfiles-usuarios.png"
  alt="Cuatro perfiles de usuario: estudiante, gamer, creador de contenido y oficina"
  className="img-center"
/>

| Usuario | ¿Para qué utiliza el ordenador? |
|---|---|
| **Estudiante** | Navegar, Classroom, documentos, presentaciones y vídeos. |
| **Gamer** | Videojuegos. |
| **Creador de contenido** | Edición de fotografía y vídeo. |
| **Oficina** | Navegador, correo, documentos y videollamadas. |

Todos utilizan ordenadores, pero **sus necesidades de hardware pueden ser muy diferentes**.

Por ejemplo, una persona que quiere jugar a videojuegos exigentes puede necesitar una tarjeta gráfica potente, mientras que para realizar documentos y navegar por Internet probablemente no sea necesaria.

:::tip[Idea clave]

No existe simplemente **«el mejor ordenador»**.

Existe **el ordenador más adecuado para unas necesidades y un presupuesto determinados**.

:::

Esta será una de las ideas principales de toda la unidad.

## 6️⃣ Piensa antes de continuar

Dos ordenadores cuestan exactamente lo mismo.

### 🟪 Ordenador A

- Componentes muy potentes.
- Poca capacidad de almacenamiento.
- Es pesado.
- Tiene poca autonomía.

### 🟦 Ordenador B

- Componentes menos potentes.
- Buena autonomía.
- Es ligero.
- Tiene suficiente capacidad de almacenamiento.

**¿Cuál es mejor?**

La respuesta es:

> **Depende de para qué lo necesitemos.**

Antes de comparar ordenadores debemos preguntarnos:

1. ¿Quién lo va a utilizar?
2. ¿Para qué lo va a utilizar?
3. ¿Qué programas necesitará?
4. ¿Necesita transportarlo?
5. ¿Qué presupuesto tiene?

:::tip[Objetivo de la unidad]

En los siguientes apartados aprenderemos a interpretar las características de un ordenador para poder **comparar equipos y elegir el más adecuado para cada situación**.

:::

---

## 7️⃣ Qué debes recordar

Al terminar este apartado deberías tener claras estas ideas:

- **Hardware** = componentes físicos.
- **Software** = programas, instrucciones y datos.
- El **sistema operativo** permite gestionar el hardware y ejecutar aplicaciones.
- Hardware y software **trabajan conjuntamente**.
- No todos los usuarios necesitan el mismo hardware.
- Un ordenador no es mejor simplemente por tener cifras mayores.
- Para elegir un equipo debemos relacionar **necesidades, características y presupuesto**.

:::info[En resumen]

Cuando compares dos ordenadores no preguntes solamente **«¿cuál es más potente?»**.

Pregunta primero:

**«¿Para qué se va a utilizar?»**

:::
