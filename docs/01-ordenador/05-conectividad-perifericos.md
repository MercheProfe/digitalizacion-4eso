# Conectividad y periféricos

Un ordenador no funciona aislado. Necesitamos conectarlo a una pantalla, una red, unos auriculares, una memoria USB, un teléfono móvil y muchos otros dispositivos.

Para hacerlo utilizamos diferentes **puertos, conexiones y tecnologías inalámbricas**.

En este apartado aprenderemos a reconocer las conexiones más habituales y a elegirlas según el dispositivo y la tarea que queramos realizar.

  src="/digitalizacion-4eso/img/ud1/conectividad-perifericos.png"

:::tip[Objetivo]

Al terminar este apartado deberías ser capaz de **identificar los principales puertos y conexiones de un ordenador, relacionarlos con los periféricos adecuados y valorar la conectividad al comparar equipos**.

:::

## 1️⃣ ¿Qué es un periférico?

Un **periférico** es un dispositivo que se conecta a un ordenador para permitir la entrada o salida de información o ampliar sus funciones.

En el punto 2 ya vimos tres grupos:

- **Entrada:** teclado, ratón, micrófono, webcam o escáner.
- **Salida:** monitor, altavoces, auriculares, impresora o proyector.
- **Entrada y salida:** pantalla táctil, memoria USB, disco externo o tarjeta de red.

:::info[Recuerda]

Un periférico necesita alguna forma de **comunicarse con el ordenador**. Esta comunicación puede realizarse mediante un cable o de forma inalámbrica.

:::

## 2️⃣ USB: una conexión para muchos dispositivos

**USB** (*Universal Serial Bus*) es uno de los sistemas de conexión más utilizados.

Podemos utilizarlo para conectar teclados, ratones, impresoras, memorias USB, discos externos, webcams, teléfonos móviles, mandos y muchos otros dispositivos.

Pero **USB no identifica una única forma de conector ni una única velocidad**.

### 🟩 USB-A

El **USB-A** es el conector rectangular clásico que encontramos desde hace años en ordenadores y otros dispositivos.

Sigue siendo habitual para conectar teclados, ratones, memorias USB y numerosos periféricos.

### 🟧 USB-C

El **USB-C** es un conector más pequeño y reversible: podemos introducirlo en cualquiera de sus dos orientaciones.

Cada vez está más presente en ordenadores portátiles, teléfonos, tabletas, monitores, cargadores y unidades externas.

<img
  src="/digitalizacion-4eso/img/ud1/usb-a-usb-c.png"
  alt="Comparación visual entre conectores USB-A y USB-C"
  className="img-center"
/>

:::warning[Importante]

**USB-C describe el tipo de conector, no todas sus capacidades.**

Dos puertos USB-C físicamente iguales pueden admitir diferentes velocidades y funciones. Dependiendo del equipo, un USB-C puede servir para transferir datos, cargar el dispositivo, conectar una pantalla o realizar varias de estas funciones.

:::

## 3️⃣ Conectar una pantalla

Para enviar imagen y sonido desde el ordenador hasta un monitor, televisor o proyector podemos encontrar distintas conexiones.

### 🟥 HDMI

**HDMI** (*High-Definition Multimedia Interface*) es una conexión muy habitual para transmitir **vídeo y audio digital**.

Podemos encontrarla en ordenadores, monitores, televisores, consolas y proyectores.

### 🟪 DisplayPort

**DisplayPort** es otra conexión digital de vídeo y audio, frecuente en ordenadores de sobremesa, tarjetas gráficas y monitores.

Determinados puertos USB-C también pueden transportar señal de vídeo si el equipo es compatible.

:::info[Situación práctica]

Si quieres conectar tu portátil al proyector del aula, debes comprobar **qué conexiones tiene el portátil y cuáles acepta el proyector**.

Si no coinciden, puede ser necesario utilizar un adaptador.

:::

## 4️⃣ Conexiones de red

Las dos opciones que encontraremos con más frecuencia para conectar un ordenador a una red son **Ethernet y Wi-Fi**.

### 🟦 Ethernet

**Ethernet** permite conectar el ordenador a una red mediante cable.

En muchos equipos se utiliza un conector conocido habitualmente como **RJ45**.

Una conexión Ethernet suele ofrecer buena estabilidad, baja latencia y menor dependencia de las interferencias inalámbricas.

### 🟩 Wi-Fi

**Wi-Fi** permite conectarnos a una red de forma inalámbrica.

Su principal ventaja es la movilidad. Su funcionamiento puede verse afectado por la distancia al punto de acceso, los obstáculos y las interferencias.

<img
  src="/digitalizacion-4eso/img/ud1/ethernet-wifi.png"
  alt="Comparación visual entre conexión Ethernet por cable y conexión Wi-Fi"
  className="img-center"
/>

:::tip[Idea clave]

No debemos pensar que **cable significa antiguo** e **inalámbrico significa mejor**.

Wi-Fi aporta movilidad. Ethernet puede resultar especialmente útil cuando buscamos una conexión estable.

:::

## 5️⃣ Bluetooth

**Bluetooth** es una tecnología inalámbrica pensada principalmente para conectar dispositivos a corta distancia.

Podemos utilizarla con auriculares, altavoces, ratones, teclados, mandos o teléfonos móviles.

No sustituye al Wi-Fi: ambas tecnologías tienen objetivos diferentes.

| Wi-Fi | Bluetooth |
|---|---|
| Principalmente conecta el equipo a una red | Principalmente conecta dispositivos cercanos |
| Permite acceder a Internet a través de una red | Muy utilizado con periféricos |
| Mayor alcance habitual | Corto alcance habitual |

## 6️⃣ Audio y lectores de tarjetas

El conector de **3,5 mm** se utiliza habitualmente para auriculares, altavoces o micrófonos. También podemos utilizar dispositivos de audio mediante USB o Bluetooth.

Algunos ordenadores incluyen lectores para tarjetas **SD** o **microSD**. Pueden resultar útiles para transferir fotografías, vídeos y otros archivos desde cámaras y otros dispositivos.

No todos los portátiles incluyen lector de tarjetas, por lo que puede ser una característica interesante para determinados usuarios.

## 7️⃣ ¿Por qué importa la conectividad al comprar un ordenador?

Cuando comparamos equipos debemos preguntarnos también:

- ¿Cuántos puertos USB tiene?
- ¿Tiene USB-A y USB-C?
- ¿Permite conectar un monitor externo?
- ¿Tiene HDMI?
- ¿Dispone de Ethernet?
- ¿Tiene Wi-Fi y Bluetooth?
- ¿Tiene lector de tarjetas?
- ¿Tiene conexión para auriculares?

:::tip[Ejemplo]

Un alumno que lleva el portátil al instituto puede valorar especialmente **Wi-Fi, Bluetooth, USB-C, algún USB-A y HDMI**.

Una persona que trabaja habitualmente con fotografía puede valorar además disponer de **lector de tarjetas SD**.

:::

## 8️⃣ El problema de los adaptadores

Algunos portátiles muy finos incluyen pocos puertos físicos.

Por ejemplo, un equipo puede disponer únicamente de dos conexiones USB-C. En ese caso podemos necesitar un **hub** para añadir USB-A, HDMI, Ethernet o lector de tarjetas.

```text
Portátil
   │
 USB-C
   │
   ▼
┌──────────── HUB ────────────┐
│ USB-A │ HDMI │ Ethernet │ SD │
└─────────────────────────────┘
```

:::warning[Antes de comprar]

Si un ordenador necesita adaptadores para conectar los dispositivos que utilizamos habitualmente, debemos considerar también **su precio y la comodidad de uso**.

La conectividad también forma parte de la elección del equipo.

:::

## 🔟 Analiza dos portátiles

Imagina que encontramos estos dos equipos con características internas y precios similares.

### 🟧 Portátil A

```text
2 × USB-A
1 × USB-C
HDMI
Ethernet
Wi-Fi
Bluetooth
Lector SD
```

### 🟥 Portátil B

```text
2 × USB-C
Wi-Fi
Bluetooth
```

Un alumno quiere utilizar el ordenador en casa y en el instituto. Tiene un ratón USB-A y quiere conectarlo algunas veces al proyector del aula mediante HDMI.

¿Podría utilizar el Portátil B?

Sí, pero probablemente necesitaría **adaptadores o un hub**. Por tanto, al comparar ambos equipos deberíamos considerar también ese coste y la comodidad de uso.

:::tip[Para la práctica final]

Cuando investigues un ordenador, no copies únicamente:

**CPU + RAM + SSD**

Revisa también sus **puertos y conexiones**.

Una buena elección debe adaptarse a la forma real en la que el usuario utilizará el equipo.

:::

## 1️⃣1️⃣ Qué debes recordar

- Los periféricos permiten introducir, recibir o intercambiar información.
- **USB-A** y **USB-C** son tipos de conectores.
- Que un puerto sea USB-C no significa que todos los USB-C tengan las mismas funciones.
- **HDMI** y **DisplayPort** permiten conectar pantallas.
- **Ethernet** permite conectarnos a una red mediante cable.
- **Wi-Fi** permite hacerlo de forma inalámbrica.
- **Bluetooth** se utiliza habitualmente para conectar dispositivos cercanos.
- Algunos equipos incorporan lector de tarjetas SD o microSD.
- Un ordenador con pocos puertos puede necesitar un **hub o adaptadores**.
- La conectividad debe valorarse al comparar ordenadores.
