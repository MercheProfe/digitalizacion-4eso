# Google Docs: documentos claros y bien organizados

Google Docs es un procesador de textos en línea. Permite crear, editar, organizar y compartir documentos desde el navegador. Los cambios se guardan automáticamente en Google Drive.

En este taller aprenderás a **mejorar un documento sin cambiar su contenido**.

## 1️⃣ Crear, abrir y nombrar un documento

1. Entra en [Google Drive](https://drive.google.com/).
2. Abre el documento facilitado en Classroom.
3. Selecciona **Archivo > Crear una copia** si el documento es de solo lectura o si tu profesor lo indica.
4. Haz clic en el nombre del archivo, arriba a la izquierda, y escribe `Apellido_Nombre_RescataDocumento`.
5. Guarda la copia en tu carpeta de Digitalización.

:::info
Google Docs guarda los cambios automáticamente. No necesitas pulsar «Guardar».
:::

## 2️⃣ Seleccionar y dar formato al texto

Para modificar una parte del documento, **selecciona primero el texto**.

| Herramienta | Para qué sirve | Consejo |
|---|---|---|
| Fuente y tamaño | Elegir letra y tamaño | Usa una fuente legible y un tamaño uniforme |
| **Negrita** | Destacar palabras importantes | No pongas todo el párrafo en negrita |
| *Cursiva* | Dar énfasis puntual | Úsala con moderación |
| Color de texto | Cambiar el color | Prioriza el contraste y la legibilidad |
| Alineación | Colocar el párrafo | El texto normal suele leerse mejor a la izquierda |

**Atajos útiles:** `Ctrl+B` (negrita), `Ctrl+I` (cursiva), `Ctrl+Z` (deshacer) y `Ctrl+Y` (rehacer), en muchos equipos Windows.

## 3️⃣ Títulos y estilos

Los estilos ayudan a organizar el documento y a mantener un diseño coherente.

1. Selecciona el título principal.
2. Abre el desplegable que normalmente muestra **Texto normal**.
3. Elige **Título** para el nombre del documento.
4. Para los apartados, usa **Título 1**; para sus subapartados, **Título 2**.
5. Mantén la misma jerarquía en todo el documento.

:::tip
No basta con aumentar el tamaño o poner negrita: los estilos identifican la estructura del documento y facilitan la navegación.
:::

## 4️⃣ Párrafos, espaciado y alineación

Un documento legible necesita espacio entre ideas.

- Divide los bloques extensos en párrafos.
- Usa **Formato > Interlineado y espaciado entre párrafos** para ajustar el espacio.
- Evita introducir muchas líneas vacías pulsando `Enter` repetidamente.
- Usa la alineación a la izquierda para el texto habitual.

## 5️⃣ Listas con viñetas y numeración

Las listas sirven para presentar pasos, consejos o elementos relacionados.

1. Selecciona las líneas que quieres convertir en lista.
2. Haz clic en **Lista numerada** cuando el orden sea importante.
3. Usa **Lista con viñetas** cuando el orden no importe.
4. Comprueba que cada elemento ocupa su propia línea.

**Ejemplo:** una secuencia de pasos para crear una contraseña segura puede ir numerada. Una colección de recomendaciones puede usar viñetas.

:::warning
No escribas manualmente «1., 2., 3.» si necesitas una lista numerada: utiliza la herramienta de listas de Google Docs.
:::

## 6️⃣ Insertar y editar tablas

Las tablas ayudan a comparar datos de manera clara.

1. Sitúa el cursor donde quieres la tabla.
2. Selecciona **Insertar > Tabla**.
3. Elige el número de filas y columnas.
4. Escribe los datos en las celdas.
5. Revisa que los encabezados sean claros y que el texto se pueda leer.

| Hábito | Recomendación |
|---|---|
| Contraseñas | Usa claves largas y diferentes |
| Actualizaciones | Instálalas desde fuentes oficiales |
| Enlaces | Comprueba el destino antes de abrirlos |

## 7️⃣ Insertar imágenes y enlaces

- Para una imagen: **Insertar > Imagen** y selecciona su origen.
- Para un enlace: selecciona el texto y usa **Insertar > Enlace** o `Ctrl+K`.
- Ajusta el tamaño de las imágenes sin deformarlas y comprueba que tengan relación con el contenido.
- Evita utilizar imágenes con datos personales o sin permiso.

## 8️⃣ Revisar, compartir y entregar

1. Comprueba la ortografía y la presentación.
2. Verifica que el archivo tiene el nombre solicitado.
3. Pulsa **Compartir** y concede acceso al docente según las indicaciones de Classroom.
4. Evita seleccionar «Cualquier persona con el enlace» si no es necesario.
5. Copia el enlace y entrégalo en la tarea correspondiente.

:::tip
Si cometes un error, utiliza **Ctrl+Z**. Si necesitas recuperar una versión anterior, consulta **Archivo > Historial de versiones**.
:::
