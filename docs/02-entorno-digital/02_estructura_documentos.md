# Cómo estructurar un documento profesional en Google Docs

Un documento bien presentado permite comprender las ideas y encontrar la información rápidamente. Para conseguirlo, no basta con cambiar tamaños de letra: necesitamos **estructura**.

## 1️⃣ Partes de un documento

Un informe académico suele contener **portada**, **índice**, **introducción**, **desarrollo**, **conclusiones** y, cuando se consulten fuentes, **referencias**. La estructura se adapta a la finalidad del documento.

## 2️⃣ La portada

Incluye un título claro, nombre de la persona o equipo, curso y fecha. Puede llevar un subtítulo o una imagen discreta.

**Cómo hacerla:** escribe los datos en la primera página, alinea y distribuye los elementos con espacios de párrafo. Para pasar a la siguiente página, usa **Insertar → Salto → Salto de página**.

:::warning
No pulses Intro muchas veces para crear una página nueva: el diseño se descolocará al editar el texto.
:::

## 3️⃣ Estilos y jerarquía de títulos

Los estilos identifican el nivel de cada apartado: **Título 1** para secciones principales y **Título 2** para subsecciones. «Texto normal» corresponde a los párrafos.

1. Selecciona el texto del encabezado.
2. Abre el desplegable que normalmente dice «Texto normal».
3. Elige **Título 1** o **Título 2** según su nivel.
4. Repite en todos los apartados.

:::info
Una frase en negrita y tamaño grande no equivale a un título estructurado. Los estilos permiten generar el esquema del documento y un índice automático.
:::

## 4️⃣ Índice automático

El índice se crea a partir de los estilos de título.

1. Sitúa el cursor en la página destinada al índice.
2. Abre **Insertar → Tabla de contenido** (en algunas interfaces está dentro de «Elementos de página»).
3. Elige un diseño con enlaces o números de página, según esté disponible.
4. Si cambias apartados, utiliza la opción **Actualizar** del índice.

:::tip
Comprueba que todos los apartados aparecen en el índice. Si falta alguno, revisa su estilo.
:::

## 5️⃣ Encabezados y pies de página

El **encabezado** se repite en la parte superior; el **pie** aparece en la inferior. Se utilizan para identificar el documento y mostrar la numeración.

1. Abre **Insertar → Encabezado y pie de página** o la opción equivalente de «Elementos de página».
2. Escribe un título abreviado en el encabezado.
3. Inserta los **números de página** desde el menú Insertar.
4. Si quieres una portada limpia, activa **Primera página diferente**.

:::info
Los encabezados, pies y determinadas opciones de paginación requieren trabajar en formato **Páginas**, no «Sin páginas».
:::

## 6️⃣ Diseño y legibilidad

- Usa una tipografía legible, como Arial, de 11 o 12 puntos para el cuerpo.
- Mantén el mismo tamaño y color en los títulos del mismo nivel.
- Utiliza márgenes, interlineado y espacios entre párrafos consistentes.
- Evita colores de poco contraste y exceso de efectos.
- Revisa ortografía y distribución antes de entregar.

## 7️⃣ Lista de comprobación

- [ ] La portada contiene título, autoría, curso y fecha.
- [ ] Los apartados tienen estilos Título 1 / Título 2.
- [ ] El índice es automático y está actualizado.
- [ ] El encabezado identifica el documento.
- [ ] La numeración funciona y la portada está tratada correctamente.
- [ ] No hay saltos creados con muchos Intro ni páginas vacías.

## 8️⃣ Practica lo aprendido

Abre un documento de varias secciones y conviértelo en un informe. Primero crea la portada; después aplica estilos, genera el índice, inserta encabezado y numeración y revisa el resultado.
